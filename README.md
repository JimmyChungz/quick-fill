# Quick Fill

本地保存登录与身份资料的 Chromium 扩展。可搜索和管理多账号、在网页选择填充、提交登录时询问保存，并导入导出备份。

## 安装和更新

需要 Chrome 120 或更高版本。自用版本在扩展管理页启用开发者模式，加载构建后的 dist 文件夹。保留该目录和 manifest 中的公钥，以维持扩展 ID。更新已有安装使用部署脚本后正常重新加载；不要移除再重装。ZIP 是本地分发包，未声称已由 Chrome Web Store 签名。

新建或编辑记录会打开独立扩展标签页，可切回网页查看资料。字段区单独滚动，保存和取消始终可用。未保存草稿只留在页面内存，浏览器崩溃或强制关闭不能保证恢复。密码库锁定或清空会清除草稿。

## 密码库与备份

保存或导入登录密码前必须先在管理页设置至少8字符的主密码，开启加密。已有明文库不会自动迁移，仍可读取、填写、导出和删除；保存或更改登录密码前需自行设置主密码。程序验证加密与读回后再切换，保留私有加密恢复副本。主密码不会上传或持久保存；遗失主密码无法找回。

启用后使用 AES-256-GCM 与 PBKDF2-SHA256，派生参数和安全边界见[安全说明](docs/SECURITY.md)。解锁会话最多15分钟，浏览器/扩展重启后锁定。活跃HTTP(S)网页会直接显示扩展来源解锁框，无需先进入管理页；关闭后聚焦表单输入框可重开。主密码不会传给网站或内容脚本，最低8字符，推荐独特且更长的密码。建议优先导出加密备份，恢复时输入该备份的主密码。旧版扩展不能读取加密库，回滚程序前必须考虑数据兼容。明文导出仍须明确确认，文件包含密码，请妥善保管。

网页只获取当前站点的账号摘要与身份字段名，用户选填时才请求单条实际记录。iframe、验证码/支付卡、跨站SSO账号推断和云同步不在支持范围内。

## 构建与检查

使用 Node 24.15+：

```sh
npm ci
npm run verify
npx playwright install chromium
npm run test:browser
npm run package
npm run deploy
```

build/watch 只写 .build/extension。deploy 验证固定 ID 和版本，备份当前 dist，保留目录，最后替换 manifest；失败回滚。运行脚本前请阅读源码与正式使用说明。

```sh
node qa/login-fixture-server.mjs --self-test
node qa/login-fixture-server.mjs
```

浏览器验收应使用合成凭据，分别记录原生提交、SPA、注册改密负向、重复/更新、后台唤醒和多标签结果。自动化测试通过并不意味着任意网站均兼容。曾报告的DOTS场景已获得用户正常使用确认；连续十次人工验收不再作为发布门槛。

## 隐私与发布状态

无账号服务器、遥测、远端上传或云同步。详见[隐私说明](docs/PRIVACY.md)。不要上传浏览器存储、真实导出文件、恢复资料、主密码或日志中的凭据。可选流程诊断默认关闭，短期事件不含密码与网址。

本项目采用[MIT许可证](LICENSE)。公开源码不包含私有Git历史、个人恢复资料或内部发布证据。软件按许可证约定的现状提供，自动测试和已知站点使用反馈不能证明任意网站均兼容。

清空所有会清除当前记录和扩展内部恢复副本，外部导出文件与系统/浏览器历史副本不会被自动删除或加密。
