重启后图标或卡片不见了

先在 Chrome 右上角的拼图菜单中查找快填，再打开 chrome://extensions 查看卡片是否存在、是否启用，以及是否出现错误提示。未固定图标、扩展停用、页面打不开是不同情况。单凭图标不见或页面打不开，不能判断扩展已经卸载。

本页若无法打开，请从 chrome://extensions 的快填卡片核对 ID 和版本；如果找不到卡片，先确认是否打开了安装快填时使用的 Chrome 个人资料。记录看到的提示后再处理。

本地未打包版本请保持开发者模式开启，保留加载时的固定目录和 manifest key，使路径与 ID 保持稳定。更新已有安装时覆盖固定目录内的文件，再点击卡片上的重新加载；不要移除后重装，也不要通过改 Chrome 偏好设置或 flags 绕过限制。

如果希望关闭开发者模式并获得常规自动更新，需要 Chrome Web Store 分发，或符合条件的企业策略部署。自行打包的 CRX 不能作为普通 macOS Chrome 用户绕过这些限制的方案。
