# 隐私说明

Quick Fill 将用户主动保存的登录和身份资料保存在本机浏览器扩展区域。项目没有账号服务器、遥测、广告或云同步，不上传这些记录。扩展需要在网页中识别表单并填入用户选择的资料；填入网站的值自然可由该网站读取。

保存或导入登录密码前要求用户主动设置主密码并开启加密。升级不会自动选择主密码或迁移旧库。未迁移的已有记录仍为应用层明文，能够读取、填写、导出和删除，但新的登录密码保存/修改需要先开启加密。用户设置主密码并确认迁移后，记录以认证密文保存；主密码不持久保存，派生解锁材料仅在受信任的扩展会话内存区域存在，最多15分钟。解锁期间、设备或扩展执行环境被攻破时不能保证保密。

默认备份入口提供加密文件；显式明文导出会警示文件含密码。恢复、清空和主密码变更均需用户操作。主密码遗失没有服务器找回机制。浏览器移除扩展可能删除本地数据，操作前应自行备份。

内容脚本收到当前站点登录摘要及身份字段名称，用户选择后才请求单条填充值。管理、导出、清空和密钥操作仅允许受信任扩展页面。未确认登录候选仅保留短期会话状态，不作为正式记录；锁定、清空与过期使其失效。

可选诊断需手动开启，默认关闭。它仅记录有限流程事件、结果码、存在标记和操作/标签编号，最多100条，十分钟后失效；不记录账号值、密码、网址、请求体或原始错误，不上传。关闭可清空。

私有浏览器恢复资料、个人日志、导出文件、历史会话和回滚备份不得进入公开源码包。当前发布预览不等于 Chrome Web Store 已审核上架。

清空所有会清除当前记录和扩展内部恢复副本，外部导出文件与系统/浏览器历史副本不会被自动删除或加密。

0.5.0网页解锁主密码仅从扩展来源输入框发送给扩展后台；网站与内容脚本仅处理挑战编号和结果。可选保存诊断增加点击/发送/回执/有限错误步骤，不包含账号、密码或网址。存储容量检查仅核对本机字节数，不上传。

权限只覆盖HTTP(S)网页，不在本地file页面或其他协议注入。恢复时未经认证的旧主库只进入单个加密取证槽，不替换可用的已有恢复副本。清空的最后一步才提交空主库；此前已撤销候选并删除内部恢复副本，外部备份仍需用户自行管理。

0.6.1查看解锁密码仅由用户点击眼睛触发，继续编辑或离开窗口即重新隐藏，不额外记录输入。lastUsedAt只在本机记录最近使用时间。旧明文提示只显示记录数量，不自动迁移、不上传；用户设置主密码并明确确认后才加密。
